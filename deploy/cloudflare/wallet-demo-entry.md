# Dual-mode Player entry

PLAY (ETB) launches a Superwin-owned internal ETB game in the existing Player. For a signed-in, play-enabled user with existing credit, PLAY DEMO also opens the same wallet-backed Superwin engine, as requested by the owner. At zero credit or without login, PLAY DEMO opens the official provider public demo. No wager occurs on entry: the funded player sees the real ETB wallet, ETB stake controls and an explicit PLAY (ETB) wager button inside the owned game. These are separate implementations: the external provider demo does not submit bet outcomes to the wallet. The ETB version is visibly branded SUPERWIN, the provider version DEMO.

POST /api/gateway/launch accepts only the selected game_id and mode. ETB entry resolves the existing wallet session and canonical /api/me Player identity, verifies role/play permission and a positive real wallet balance, then returns the same-origin /native/<id>?embed=1 route with settlement_enabled=true. Opening the page does not place a wager. The owned engine's authenticated action API handles the actual stake, server result and payout in the shared PostgreSQL ledger. Provider-demo entry does not debit or credit the wallet. A funded entry selected through either lobby button uses the owned engine; its explicitly submitted ETB spins settle on the same wallet.

The 30 active engine IDs match the selected catalog IDs. All previous 30 engine IDs are restricted to receipt replay and accepted-round recovery. The original native three-game routes are preserved. The engine reserves its full maximum payout from existing house funds and rejects unaffordable player or house risk without leaving a partial wager. No accounts or funds are seeded.

The ETB iframe sends same-origin balance notifications after authoritative snapshots and receipts. Parent checks the exact frame, current wallet identity, canonical user ID, game ID and currency before updating its display. Browser outcome or payout fields are not accepted by settlement. A stale cached positive balance cannot bypass the fresh backend entry check. Logout and session changes close the iframe and abort pending entry requests.

The old test popup, explanatory test paragraphs and stake-check form are removed. /api/wallet/test returns 410. The visible controls are PLAY (ETB), PLAY DEMO and the ordinary game controls. External SmartSoft financial settlement remains separate and unconfigured until the official provider contract is supplied; Superwin's internal ETB settlement works independently.
