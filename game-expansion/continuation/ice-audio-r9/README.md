# Burning Ice 10/40 source audio continuation

Published 2026-11-10 UTC on the existing Superwin Player and Library. No new
site, wallet, account, backend, cash release gate or engine was created.

- Player v353: `07f133a6-5deb-4b88-9ed2-6478aa6e3298`.
- Library v32: `15e2c8a2-a8aa-4cb1-a86a-8a09cd3e3e83`.
- Base Player v351 and Library v31 remain the recovery pair. Round actors,
  schemas, old modules, wallet bindings, assets and exports were retained.

The official free DMO BlazingHot10 and BlazingHot40 pages supplied the
original AUTO number, reel-loop and freeze/unfreeze logo audio. SHA-256,
normal 200 responses and public source callback facts are in provenance.json.
The meter Header sound was also observed, but is outside this release until
its timing is resolved. No other title's sound is substituted.

AUTO count selection now emits AutoPlay/Number. The reel loop starts at the
public first-moving-reel callback and stops on the final reel's impact or
completion; cancellation owns an AbortSignal so delayed decoding cannot
restart stale audio. This effect remains audible when music alone is muted.
Existing spin, result, collect and win-clock behavior is retained.

The canonical demo adapter rewrites games.json to demo-games.json. Ther10
thin Player wrapper selects the r9 pinned catalogue at this exact boundary;
all previously served r9 resources remain immutable. Authenticated entry
URLs continue to use the existing signed remaining20 transport and server
release decision. This release does not approve real-money play.

Verification:

- 49 asset, routing, ownership and preservation checks.
- Canonical createDemoMode resolution for both titles.
- Chromium decoded all four new sounds for each title, verified one reel loop
  and stop, music separation, immutable accepted grid, cancelled audio and
  actual native 25-spins button callbacks. These were component tests with no
  financial requests; they are not an authenticated wallet round test.
- Live Chromium verified 14 asset hashes and 4 entry shells, with no JavaScript
  errors or financial POSTs during the component run.

The first Library upload exceeded startup CPU. Deferring the new immutable
asset catalogue until its namespace is requested passed upload validation.
The Player upload succeeded but a combined old/new body verification exceeded
the connector's memory limit. Separate bounded metadata/hash runs verified
every prior module before activation. Neither failure changed the active site.

The complete executable public module is remaining20-ice-audio-assets-r9.mjs;
it contains the pinned presentation inputs and source-verified audio bytes.
Private engine bundles and authentication material are not included.
