Observed by the root agent on 19 November 2026 in the official SmartSoft DMO browser demo, game version 1.0.1. This note records the root agent's direct Help/Rules inspection; the reference-research agent did not play the demo.

Official entry: <https://www.smartsoftgaming.com/games/wild-multi-stars>
