This six-part public bundle preserves30 original non-history screenshots from the current official demo. Each image, part and complete ZIP has a pinned digest in `index.json`. These images are reference evidence only, never renderer assets or playable round frames.

Restore using the shared audited materializer:

```sh
python3 codex-work/new-games72-20261121/evidence-bundle/materialize.py --index codex-work/new-games72-20261121/evidence-bundle/multi-hot-10/index.json --root .
```

All30 images were independently restored with matching bytes; a repeated run wrote zero files and kept30 unchanged. The original compressed transfer ZIP stays outside the repository to avoid duplicate binary publication. The two history screenshots are excluded. No production account data or runtime launch token is included.
